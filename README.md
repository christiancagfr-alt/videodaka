# 静心：YouTube 视频学习与灵修客户端

Python 3.12 + PySide6 桌面应用。代码、启动脚本和本地数据均位于当前目录。首次使用建议先运行 `python main.py --demo`，在设置填写登记人，在分类框输入分类，点击登记。默认 local 模式，不访问或修改在线表格。

## 启动与验证

```powershell
python -m pip install --only-binary=:all: --require-hashes -r requirements.lock
python main.py
python -m unittest discover -s tests -v
python main.py --smoke --data-dir .smoke-data
```

Windows 源码版可双击“启动.bat”。Linux/macOS 安装依赖后运行 main.py。

## 安装包与 GitHub 构建

仓库的 **Actions → Build installers** 为 Windows x64、macOS Apple Silicon 和 macOS Intel 分别构建安装包。推送 main 或手动运行即可触发；完成后从对应任务的 Artifacts 下载 EXE 安装程序或 DMG。每个产物附带 SHA-256 校验文件。

这些是未使用商业证书签名、未经 Apple 公证的安装包，Windows SmartScreen 和 macOS Gatekeeper 可能提示开发者身份未验证。macOS 使用 DMG 中的应用拖入 Applications 安装。Windows 安装到当前用户目录，无需管理员权限。应用启动后会自动检查 GitHub 最新正式版本；发现更新时可在应用内下载适配当前系统的安装包，并验证 GitHub 提供的 SHA-256 摘要。Windows 会启动安装程序；macOS 会打开已下载的 DMG，需将应用拖入 Applications 并替换旧版。检查失败不会影响使用。

构建使用 Python 3.12 的可用最新补丁版本、带哈希的依赖锁文件、PyInstaller 目录模式和 Inno Setup。可以在对应系统执行：

```text
python -m pip install --only-binary=:all: --require-hashes -r build-requirements.lock
python packaging/build.py
```

Windows 本机构建需安装 Inno Setup 6；macOS 使用系统 hdiutil。不能在 Windows 上直接生成可用的 macOS 应用。构建会测试打包后的网页渲染、全屏和下载器启动；不会带入个人表格、授权 JSON、浏览器 Cookie 或观看记录。下载需要 FFmpeg 合并高画质音视频；首次下载时若检测不到 FFmpeg，默认通过 Windows winget 或 macOS Homebrew 自动安装，也可以在下载设置关闭自动安装并手动指定程序路径。Node 为可选组件。

安装版数据保存到系统当前用户的应用数据目录（Qt AppLocalDataLocation/DevotionFlow），源码版仍使用项目的 data 目录。可通过 `--data-dir` 指定数据目录。迁移时先关闭程序，再复制原数据，并重新选择 Google OAuth 桌面应用 JSON；卸载不会主动删除个人数据。

## 日常操作

播放页新增“截图”和“下载”：截图只保存 YouTube 视频画面区域，不包含播放器周围界面；截图设置中可配置目录及每 5、10、15、30 或 60 秒自动截取（仅播放期间）。自动截图默认关闭，手动截图按钮直接抓拍并保存。下载采用 yt-dlp，默认最高 1080p，可选 720p、1440p、2160p 或源视频最高画质；在独立下载设置中选择“边看边下载”和保存路径。默认输出 MKV 以兼容源编码。清晰度受源视频实际格式限制。

在含 `list=` 的 YouTube 链接上点击“下载 → 同步当前播放列表”，软件会读取列表并批量下载，保存下载档案、跳过已完成视频；下次再次点击同步可下载列表新增视频。下载时可以继续观看，关闭下载窗口不停止任务；“停止下载”或退出主程序会停止进程，部分文件保留供再次启动续传。当前没有后台定时巡检列表功能。登录限制、网站变动或源格式不可用会在下载窗口显示错误。

视频草稿按登记人、模式与视频分别保存在 SQLite 中，包含累计观看区间、播放位置、分类、感想和本轮登记 ID。进度每秒自动保存，文本编辑后约 350 毫秒保存，正常退出也保存。重启恢复最后视频并暂停于上次位置；恢复跳转本身不计观看时长。意外断电最多可能丢失最近约一秒进度。已登记轮次不会因重启重复提交。软件更新前尚未保存的播放草稿无法追溯恢复。

分类饼图与合格数量折线按分类名称使用稳定配色，切换月份不改变颜色。下拉框和数字输入框只有获得焦点后才能用滚轮调整。小树加入叶脉、自然枝干、花盆渐变与阴影，保持从幼苗逐级成长。

内嵌 YouTube 网页提供基础广告拦截开关，拦截常见广告域名和 YouTube 广告接口。部分广告与视频共用 CDN，不能保证完全无广告；若视频播放异常，可在设置中关闭拦截并刷新页面。

设置页还可安装本地解压的 Chrome 扩展目录（仅 Manifest V3）。若 Chrome 已安装兼容扩展，可在 Chrome 用户配置目录下找到扩展 ID 和版本文件夹，选择其中含 `manifest.json` 的目录；应用会把它安装到自己的浏览器配置，并在私有数据目录保留恢复副本。当前 Qt WebEngine 在 Windows 上调用启用扩展接口会导致原生崩溃，因此扩展保持停用；应用内置过滤规则仍会生效。Qt WebEngine 不提供 Chrome 网上应用店界面，扩展需由用户从可信来源取得；扩展权限和 YouTube 兼容性取决于扩展本身。视频流内或服务端插入的广告仍可能无法拦截。

界面使用左侧四页导航：播放与登记、日历与小树、数据分析、系统设置。每日目标固定为 2 部合格长视频。播放页左侧为完整 YouTube 网页，右侧为快捷登记；点击“全屏”、按 F11 或使用视频自身全屏按钮进入沉浸模式，Esc 或左上角退出按钮返回。切换页面不会重新创建浏览器。

右上角头像支持在设置页选择 PNG/JPG/WebP 图片，软件将图片副本存入 data/avatars。悬浮显示当前视频观看比例与播放/登记状态、今日合格数、心情、小树阶段、等级和健康值，点击进入日历页；尚未关联 Google 登录头像。YouTube 网页登录仍在内嵌浏览器中进行，表格 Google OAuth 授权则使用系统默认浏览器。授权页返回后需等待应用显示“已连接”，应用会检查 Google 返回的权限别名并验证系统凭据库；授权请求最长等待 5 分钟，避免失败请求一直占用按钮。左上角 ☰ 收起或展开导航栏，并保存此偏好。分析页可选择月份，查看合格长视频数量折线、按登记次数的分类占比、每日长视频合格占比（无登记的日期留空）。

填写登记人和分类后，实际观看覆盖率达到 95% 会自动登记并同步。每轮只登记一次，提交后保留进度显示；如需重复观看计数，先点“开始新一轮观看”再重新播放。未达 95% 可手动登记到日志。自动登记时保存当时已输入的感想，后续输入不会修改已提交记录。本地演示页不触发自动登记。

观看时长至少 20 分钟且完整覆盖达到 95% 的视频才算合格长视频；较短视频照常登记和计入观看次数，但不给小树增加养分。每天完成 2 部合格长视频并至少写 1 篇对应观后感，才算达标。小树从幼苗开始，以 730 个满营养日（约 2 年）作为进入成树期的目标；视频或感想不足时按部分养分缓慢成长，既有记录会按新标准重新计算。成熟后不会停止：合格观看持续累积生态年龄，树干、树冠、枝条和叶片会在几十年到上百年的模型区间内逐步增大；养分不足时生长减慢，不提供手动加水或加肥入口。

1. 设置登记人、月度目标、主题和头像图片。
2. 左侧打开 YouTube 视频，右侧显示实际播放过的、不重复的内容秒数。暂停、跳转和缓冲不计时；倍速按已播放的视频内容长度计时。观看覆盖达到 95% 可登记；只有总时长至少 20 分钟的视频才计入成长目标。直播无有限总时长不能登记。
3. 选择或输入分类，填写可选感想。达到 95% 自动登记，也可提前手动登记。每次登记生成新 ID，先落盘，再进行同步。登记后本轮锁定提交，重复登记需开始新一轮并重新观看。刷新页面保留本轮累计区间；切换视频会开始新一轮。
4. 记录页可查看同步错误，每分钟及启动后可手动重试。模拟与在线数据分别统计，演示不能提交到在线表格。
5. 成长看板按本地已保存的长视频合格记录统计（包括待上传记录）。两部长视频与至少一篇观后感构成一个满营养日；不足时按比例慢速成长，达到 730 个满营养日约为成熟树。日历只在每天目标达成时标记完成。心情保存最新选择。

## Google Sheets 配置

在 Google Cloud Console 启用 Google Sheets API，创建 OAuth Client ID 并选择“桌面应用”，下载 JSON。在设置页选择该桌面应用文件，再点击“连接 Google 账号”；应用会打开系统默认浏览器，让你登录 Google 并同意 Sheets 授权。访问令牌与刷新令牌保存在 Windows Credential Locker 或 macOS Keychain，不写入配置文件。选定的 Google 账号仍必须拥有目标表格的访问权限；OAuth 登录替代服务账号密钥和手动复制服务账号邮箱，但不会绕过 Google Sheets 的表格权限。最后填写 Spreadsheet ID（链接 `/d/` 与 `/edit` 之间）、准确工作表名称并切换同步模式为 `google`。OAuth 同意屏幕若处于测试状态，需将登录账号加入测试用户。

样例仅用于验证，没有固定绑定其 ID。汇总样例日期表头第 1 行、分类第 2 行、姓名 A 列、人员从第 5 行开始，每天一个合并日期块，“认识”列追加感想。姓名为空时必须先在真实表中填写。日期需为完整日期（真实日期数值或 YYYY-MM-DD 等格式）；程序按返回的计算结果识别日期，并将日期沿分类表头向右继承。日期、类别、姓名重复匹配会阻止汇总更新。分类计数或认识栏若为公式，会拒绝覆盖。

日志兼容样例六列表头，会在尾部补齐 PRD 字段：登记时间、登记人、视频标题、视频链接、视频总时长、观看时长、分类、个人观后感、完播率、记录ID。时长单位秒。文本使用 RAW 写入，感想不会作为公式执行。每次提交都写日志；95% 及以上才更新汇总。日志成功但汇总失败时保持待重试状态。

“读取在线历史分类”读取日志的“分类”列，并可读取配置的分类工作表第一行以下数据。分类源工作表可留空。读写操作在后台线程执行。

## 数据与重试边界

`data/settings.json` 保存设置，`data/records.sqlite` 保存登记和本地模拟表，`data/browser` 保存网页 Cookie，`data/extensions` 保存已安装扩展的恢复副本。备份请关闭程序后复制 data。每条记录冻结提交时配置，后续改设置不会把旧数据误发到新表；配置填错造成的旧队列记录需修正数据库配置或重新登记，界面暂未提供队列重定向。

日志用记录ID去重。汇总单元格备注逐行追加 `• 《视频标题》`，去重ID保存到表格 developer metadata，与计数、备注和认识通过同一个 Sheets batchUpdate 写入。失败后重试先检查元数据，也兼容旧版备注中的ID标记。已有旧备注不会自动改写，请保留旧标记以兼容历史重试。Google Sheets 没有用于此方案的比较交换事务：多个设备同时修改同一单元格仍可能丢失更新，日志读后追加也无法保证跨客户端严格一次。当前版本适合单写入客户端；多设备正式部署应增加集中式同步服务。单机同一数据目录有实例锁。

YouTube 网页结构变化可能影响监测。Google 可能限制嵌入式浏览器登录，播放编解码器支持取决于 QtWebEngine 发行包；没有尝试绕过登录限制。真实 OAuth 登录、视频播放及 Google API 写入仍需要用户的 Google Cloud OAuth 配置和账号进行验收。
